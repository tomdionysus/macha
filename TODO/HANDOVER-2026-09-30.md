## What the experiment is

The destination: one versioned store of objects and the edges between them
(an object DAG in which heads pin roots), with metadata and an object ledger
as two views over it, on disk behind a bounded cache, verifiable across
nodes by a committed multiset hash. Stage 0 builds none of that storage: it
restructures the whole node into components with declared dependencies,
wired and run by a composition root, speaking only through contracts, with
three contracts (object store, metadata view, object ledger) implemented by
today's code, at operational and functional fidelity.

Why: Macha is to be Dijkstra-provable and Knuth-legible before mass peer
review, and the structure is what makes independent testing easy.

## Rules agreed this session (all in the spec's decision log)

- **Fidelity** is operational and functional, not fidelity to current code.
- **Kill criteria**: any part that, taken holistically as an operational
  system, loses fidelity to the user, becomes brittle, breaches the Laws and
  Guidelines, or is less performant, less resilient or more brittle than its
  predecessor. Quantified by T0.
- **It is an experiment**: built to find out; no step waits on up-front
  proof. Doing work twice is fine if it buys fidelity and a better system.
- **Proof**: 100% line and branch coverage of every component a step builds
  or converts, mutation-proven, with contracts stated as preconditions,
  postconditions and invariants. Coverage proves the implementation; design
  fitness is a separate, higher-order question.
- **Two classes of component and test**: a primitive is any unit whose
  phase space is small enough to test deterministically and exhaustively
  (mutexes, bounds, spans and the like are examples, not the set); beyond
  that, tests are functional or behavioural. The deterministic layer is kept
  separate. This is what inversion of control is for.
- **Sanitizers are debuggers**, pointed at a suspected fault; not evidence.
- **No CI.** Every accepted stage and substage is pushed; evidence
  (coverage, mutation record, trace comparison, timings) is committed under
  `TODO/object-ledger-evidence/<step>/`.
- **In-process testing until T5**; T0's instrumentation deploy is the one
  exception.
- **The cluster** is the only Macha cluster and disposable: avoid dropping
  the library, not at the experiment's expense. At T5, deletion is paused
  with a large `garbage_grace`, fi-1 runs the experiment beside gbni-1 on
  0.73.2 first, and each node's 0.73.2 is saved as its install backup.
- **Versions**: plain semver, no extensions, CMake and README together.
