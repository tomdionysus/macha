## How to build and deploy

fi-1 builds; **never build on gbni-1**. fi-1 has the tree at `/root/macha`
and `build/` configured with `-DCMAKE_INSTALL_PREFIX=/usr`.

1. Bump `project(macha VERSION ...)` in `CMakeLists.txt`, the `*vX.Y.Z*` line
   in `README.md` and the header of `macha.yaml.example`; CHANGELOG entry. A
   change that makes a request 0.x accepted fail is a minor bump.
2. Local: `cmake --build build -j8` then `sh run-tests.sh build` (the script
   is not executable; `./run-tests.sh` fails 126). The laptop cannot host a
   libtorrent session: every torrent test that starts one segfaults there;
   those run on fi-1.
3. Commit on `develop`, naming files (never `git add -A`). Push.
4. Sync and build on fi-1:
   ```
   rsync -a --exclude='.git' --exclude='build' --exclude='build-*' --exclude='.cache' \
     --exclude='.DS_Store' --exclude='.claude' --exclude='.codegraph' --exclude='*.swp' \
     --exclude='*.tmp' /Users/tom/devroot/macha/ root@10.35.1.10:/root/macha/
   ssh root@10.35.1.10 'cd /root/macha && rm -f /root/build.log && (setsid nohup sh -c "cmake --build build -j3 > /root/build.log 2>&1; echo BUILD_RC=\$? >> /root/build.log; sh run-tests.sh build > /root/suite.log 2>&1; echo SUITE_RC=\$? >> /root/build.log" >/dev/null 2>&1 </dev/null &)'
   ```
   Wait with a background loop polling `grep RC= /root/build.log` every 30 s
   (a Monitor once missed the result over fi-1's wifi). Read the suite
   summary (`grep -E "^All |FAIL" /root/suite.log`); every failure is P0 work
   and is measured before any deploy decision.
5. Stage and ship:
   ```
   ssh root@10.35.1.10 'rm -rf /tmp/stage-V && cd /root/macha && DESTDIR=/tmp/stage-V cmake --install build >/dev/null && tar czf /tmp/macha-V.tgz -C /tmp/stage-V usr && md5sum /tmp/macha-V.tgz'
   ssh root@10.35.1.10 'cat /tmp/macha-V.tgz' | ssh root@10.44.1.50 'cat > /tmp/macha-V.tgz && md5sum /tmp/macha-V.tgz'
   ```
6. **Gate on playback, in the same command as the install**: for each node,
   `journalctl -u macha --since -2min | grep -cE "playback stream segment|pipeline direct|session create"`
   must be 0, and the command must stop if not (on 2026-09-25 a check was
   printed and then ignored). Ask the client sessions before restarting
   under a smoke test.
7. Install fi-1 then gbni-1: back up `/etc/macha/macha.yaml` as
   `.bak-<previous>`, `systemctl stop macha`, `tar xzf ... -C /`,
   `daemon-reload`, `start`; wait for `/api/v1/health` to show the version;
   check `metadata availability changed state=writable`.
8. Tag `V` (annotated, `V: <subject>`), fast-forward `main`, push both and
   the tag. Tell Core the version per node.

## Reading a crash

gbni-1 writes cores to `/mnt/diskB/crash/core.<exe>.<pid>.<time>` (runtime
`kernel.core_pattern`, lost on reboot; the systemd drop-in with
`LimitCORE=infinity` survives). Unpack the tarball of the crashed version into
a sysroot and point gdb at it; frames show function names only. For a live
thread, `gdb -p $(pidof macha) -batch -ex "thread apply all bt 25"` pauses the
process for about a second; check for viewers first. `/proc/<pid>/task/*/`
(`comm`, `stat` fields 14+15, `wchan`, `syscall`) answers most "what is it
doing" questions without pausing anything.

## Traps that cost time today

- **libtorrent's queue manager undoes `pause()` on an auto-managed torrent.**
  Hold = unset `auto_managed`, then pause (`src/torrent_session_policy.cpp`).
  Resume data restores whatever flags it was saved with; set them from the
  job on restore.
- **A first-64-KiB read does not show a file is readable**; lost extents sit
  anywhere.
- **Import writes and repair both put to fi-1.** Attribute RPC traffic before
  blaming a subsystem; the 0.62.3 gate counters exist because three guesses
  about repair were wrong.
- **Gauges are published per pass.** A test that reads one the instant after
  an event races it; wait for the gauge.
- `macha.yaml.example`'s version line is maintained by hand.
- Background task output lands under `/private/tmp`, outside the filesystem
  boundary: have commands write their own logs under `build/` and read those.
